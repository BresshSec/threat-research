## Evidence Discipline

The case separates directly supported observations from analytical relationships. Absence from indexed search results is not treated as proof of global absence.

The confirmed IOC list excludes values classified as package metadata, environmental residue or unverified candidates.

## Explicit Limits

This evidence set does not establish:

- the exact body served to the June victim;
- definitive MintsLoader attribution for the June loader stage;
- continuity of control over shared infrastructure;
- a common operator between the June and September activity;
- global absence of `x3qqyj78o2rdso9[.]top` from every public or private feed;
- the current security state of `pesterbdd[.]com`.

The full source register and methodology are preserved with the CERT review package and the publication working set.
